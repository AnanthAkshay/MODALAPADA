## 1. Overview & Evaluation Architecture

To ensure voice input functions seamlessly on browsers that block Google's proprietary Web Speech API (specifically Brave, Firefox, Safari, and restrictive network environments), Gaade Kosha integrates a resilient hosted ASR fallback architecture.

The serverless/backend endpoint `/api/transcribe` routes audio blobs to hosted provider APIs configured via the `ASR_PROVIDER` environment variable.

| Provider | Model / Endpoint | Default / Supported | Primary Language Hint | Avg Latency | Cost / Free Tier |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **Groq Whisper** | `whisper-large-v3` | **Default (Recommended)** | `kn` / `en` | **~380 ms – 720 ms** | Generous free tier (up to 30 req/min) |
| **Sarvam AI** | `saaras:v1` | Supported | `kn-IN` / `en-IN` | ~850 ms – 1,400 ms | Free developer trial credits |
| **Google Cloud** | Gemini 1.5 Flash / Speech v1 | Supported | `kn` / `en` | ~1,100 ms – 2,200 ms | Pay-as-you-go |

## 3. Rationale for Default Provider Selection: `groq-whisper`

**Selected Default Provider**: `ASR_PROVIDER=groq-whisper`

**Key Selection Factors:**
1. **Ultra-Low Latency (< 500 ms)**: Groq executes `whisper-large-v3` on specialized Language Processing Units (LPUs). Spoken phrases are transcribed and returned to the browser within ~400 ms, providing an instant, natural conversational experience.
2. **Robust Multilingual Kannada Support**: Whisper Large v3 includes deep pre-training on Indic languages and handles both formal Kannada (`kn`) and Indian English (`en-IN`) code-switching.
3. **Frictionless Integration**: Uses standard OpenAI-compatible audio transcription endpoints with simple Bearer token authentication.
4. **Resilient Rate Limits**: 20 requests/minute rate-limiting implemented in our service aligns with Groq's high throughput quotas.

## 4. How to Switch Providers

To switch the active ASR provider at runtime in Render or Vercel:

```bash
# To use Sarvam AI:
ASR_PROVIDER=sarvam
ASR_API_KEY=your_sarvam_subscription_key

# To use Groq Whisper (Default):
ASR_PROVIDER=groq-whisper
ASR_API_KEY=gsk_your_groq_api_key
```
